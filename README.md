# pi-mentor-mode

`mentor-mode` is a Pi extension with five operating modes:

- `/mentor learn`
- `/mentor search <query>`
- `/mentor index`
- `/mentor unstuck`
- `/mentor do <description>`

It also provides:

- `web_search` tool
- `project_index` tool (writes `.pi/wiki/*`)
- `/wiki` and `/wiki search <term>` commands

## Install (local)

```bash
pi install git:github.com/<you>/pi-mentor-mode
```

Or test directly:

```bash
pi -e ./extensions/mentor-mode/index.ts
```
